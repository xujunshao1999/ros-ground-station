## Phase 1 代码审计 & Bug 修复

审计发现并修复 5 个问题：

1. **base_agent.py:315 `rc` 未定义变量 bug** → 改为 `reason_code`（与 paho-mqtt v2 签名一致）
2. **mock_agent.py 使用不存在的 `CmdAction.STOP` / `CmdAction.RETURN_HOME`** → 改为 `CmdAction.NAV_GOAL` 和 `CmdAction.CUSTOM`；增强 `CmdAction.MODE` 支持 `mode=stop` 时自动清零速度
3. **api.py action_map 缺少 stop/return_home 映射** → 增加 `stop → MODE(mode=stop)` 和 `return_home → NAV_GOAL(target=home)` 语义映射
4. **base_agent.py `_start_status_loop()` 空实现** → 补全默认实现（线程定时上报），ROS Agent 不重写也能工作
5. **base_agent.py `_store_stream_data()` 空实现** → 补全默认实现（内存字典 + 线程锁），ROS Agent 不重写也能工作

基类增强后，MockAgent 的重写变成冗余但无害，保留不改。
